# 홈페이지 없이 인스타 DM으로만 영업하시는 사장님을 위한 — 5분 만에 가게 홈페이지 만들기

컴퓨터를 잘 모르는 동네 사장님도 **디자인 고르고 → 가게 정보 적고 → 미리보기 확인하고 → 완성 버튼**만 누르면, 손님이 전화 걸 수 있는 진짜 홈페이지가 고유 주소(`/site/가게ID`)로 만들어지는 체험형 데모입니다.

## 🌱 왜 만들었는가

동네 사장님들은 장사는 잘하시는데, 홈페이지는 늘 "나중에"였습니다.
견적 받으려고 **전화 3통** 걸었는데 답이 없고, 겨우 받은 견적서는 80만원, 100만원.

홈페이지는 사장님의 또 다른 간판입니다.
그래서 만들었습니다. **5분이면 충분해요. 어렵지 않아요.**

우리의 약속: **"우리는 사장님의 일을 세상이 알아주게 만듭니다."**
높은 가치는 느끼는 사람들에게 전달되어야 합니다.
여기에 적은 가게 정보·메뉴·사진·의뢰 기록은 10년 후에도 사장님의 것입니다.
가게를 물려주는 날, 온라인 간판까지 그대로 이어받으세요.

우리가 지키는 7가지: 사람을 사람으로 · 정직 · 다크패턴 금지 · 따뜻함 · 신뢰 · 겸손 · 인내

## 타겟 고객

- **청소·이사·인테리어·미용실 업체 사장님**: 당근에 홈페이지 제작 업체가 40~300만원에 실제 영업 중인 검증된 유료 수요층
- 전화·인스타 DM으로만 영업하다가 손님을 놓치는 사장님
- 컴퓨터가 서툴러 "홈페이지는 비싸고 어렵다"고 생각하는 사장님
- **타겟 단가: 50~150만원** (기본 제작 50만원 + 선택 옵션)

## 실행 방법

```bash
bash run.sh
```

브라우저에서 접속:

- **메인**: http://localhost:5005 — 디자인 고르기 → 정보 입력 → 미리보기 → 완성하기
- **완성 홈페이지 예시**: http://localhost:5005/site/가게ID
- **내 홈페이지 관리**: http://localhost:5005/manage — 목록 · 고치기 · 지우기

(Flask가 없으면 자동으로 설치합니다. 포트 5005가 사용 중이면 자동으로 다음 빈 포트로 켜지고, 실행 화면에 실제 주소를 알려줍니다. 종료는 터미널에서 `Ctrl+C`)

## 핵심 어필 포인트

1. **짜증 오프닝**: "홈페이지 견적 받으려고 3곳에 전화했는데 답이 없어요." — 숫자로 보여주고 "5분이면 충분해요. 어렵지 않아요"로 전환
2. **사장님 오늘 브리핑** (`/briefing`): 시간대별 인사, 내 홈페이지·받은 의뢰·견적 합계, 오늘 할 일
3. **가치 계산기** (`/calculator`): 업종별 업체 평균 견적 vs 0원 → "한 번에 ○○만원 아껴요"
4. **월간 리포트** (`/report`): 만든 홈페이지·받은 의뢰·견적 합계 + 벤치마크 비교(데모 기준 표기)
5. **성장 시뮬레이터** (`/simulator`): 방문자·문의율·객단가 막대 → 예상 월 추가 매출
6. **추천 리워드** (`/referral`): 추천 코드·단톡방 공유, 추천 기록 시 배지
7. **배지** (`/badges`): 첫 홈페이지·문의 1호·알찬 가게·소문의 주인공·든든한 기록가
8. **우리의 약속** (`/about`): 사명 선언문, 왜 만들었는가, 10년 데이터 소유, 가게 이어받기, 가치 7원칙
9. **가게 이어받기** (`/export`): 전체 데이터 JSON 내려받기
10. **축하 애니메이션**: 홈페이지 완성 시 컨페티 + 축하 메시지
11. **5분 완성 체험**: 업종별 디자인 4종(미용실·청소·이사·인테리어)을 고르고 정보만 적으면 끝
12. **실시간 미리보기**: 입력하는 대로 바로 보이는 미리보기 + PC/폰 화면 전환 버튼
3. **바로 영업 가능**: 완성하면 고유 주소(`/site/가게ID`) 발급, 전화걸기 버튼이 항상 따라다님
4. **견적 자동 계산**: 도메인 연결·온라인 예약·후기 게시판 등 옵션을 고르면 견적이 즉시 계산 → "이대로 제작 의뢰하기"로 바로 영업 연결
5. **사장님 말로 된 화면**: "템플릿"→"디자인 고르기", "배포"→"홈페이지 완성하기" 등 개발자 용어 제로
6. **고객 관리 화면**: 만든 홈페이지 목록·수정·삭제 — 재방문 유도

## 기술

- Python Flask + SQLite (`sites.db` 자동 생성)
- 외부 API·유료 서비스 없음, 모든 디자인은 순수 CSS
- 한국어 UI, 모바일 반응형 (폰에서 미리보기 자동 전환)
